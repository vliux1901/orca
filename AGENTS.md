# Project Context

The `docs/` folder contains the authoritative project documentation.

Important documents:
- `docs/prd.md`: Product requirements document. Read this before making product, UX, architecture, or feature decisions.

Working rules:
- Before implementing or changing behavior, check relevant files in `docs/`.
- If code and docs disagree, surface the discrepancy instead of guessing.
- Keep docs updated when product behavior or requirements change.
