Scope

This document defines the app-owned Kotlin API contracts around documents, sources, extraction, and timeline persistence. The goal is to keep UI, repositories, Room, and cloud-provider adapters aligned behind stable internal types.

  • These are internal app contracts, not public network APIs.
  • The same contracts should support cloud extraction in V1 and a later local privacy-mode backend.
  • Entities should carry enough provenance for source-file review and fact citations.

Layering

  • Room entities model persistence shape.
  • Domain models combine entity graphs for screen and worker use.
  • Provider DTOs are adapter-local and should not leak into repositories or UI state.

Room Entities

data class VehicleEntity(
    val vehicleId: String,
    val displayName: String,
    val make: String,
    val model: String,
    val year: Int,
    val licensePlate: String?,
    val vin: String?,
    val currentMileage: Int?,
    val createdAt: Instant,
    val updatedAt: Instant,
)

data class DocumentEntity(
    val documentId: String,
    val vehicleId: String,
    val title: String?,
    val sourceCount: Int,
    val importStatus: DocumentImportStatus,
    val extractionStatus: ExtractionStatus,
    val latestRunId: String?,
    @ColumnInfo(name = "occurredAt")
    val occurredOn: LocalDate?,
    val createdAt: Instant,
    val updatedAt: Instant,
)

data class DocumentSourceEntity(
    val sourceId: String,
    val documentId: String,
    val sourceOrder: Int,
    val fileName: String,
    val mimeType: String,
    val relativePath: String,
    val byteSize: Long,
    val checksumSha256: String?,
    val pageCount: Int?,
    val createdAt: Instant,
)

VehicleEntity stores the user-managed car profile that owns documents. DocumentEntity represents one logical maintenance document. DocumentSourceEntity represents one imported file that belongs to that document. Audit timestamps use Instant, while occurredOn and eventDate use LocalDate because they represent service dates rather than exact moments.

Aggregate Models

data class DocumentAggregate(
    val document: DocumentEntity,
    val sources: List<DocumentSourceEntity>,
    val latestRun: ExtractionRunEntity?,
    val facts: List<DocumentFactEntity>,
    val event: MaintenanceEventEntity?,
    val serviceItems: List<ServiceItemEntity>,
)
  • Use aggregates for detail screens and worker pipelines so each use case reads one coherent graph.
  • Do not expose bare Room relations directly to Compose screens.

State Enums

enum class DocumentImportStatus { PENDING, READY, FAILED }
enum class ExtractionStatus { NOT_STARTED, QUEUED, RUNNING, SUCCEEDED, FAILED }
enum class ExtractionBackendType { CLOUD_VISION, LOCAL_VISION }
enum class FactType { SERVICE_DATE, ODOMETER, TOTAL_COST, SHOP_NAME, VIN, LINE_ITEM, NOTE, INTERPRETED_LINE_ITEM }

Keep enums app-owned even if providers use different labels.

Validation Rules

  • Reject malformed provider JSON before writing any facts.
  • Require citations to use app-owned sourceId and page number when available.
  • Normalize dates, costs, and mileage locally before persistence.
  • Allow missing low-confidence optional fields, but do not invent values to make the contract look complete.
  • Require interpreted shorthand expansions to retain a pointer to the raw extracted fact and never persist without evidence text or citation.
  • Allow raw extracted facts to carry a local review warning when the app detects that the extracted line text may not match the cited evidence snippet exactly.

Cost Contract

  • MaintenanceEventEntity.totalCostMinor represents the overall document total.
  • ServiceItemDraft.costMinor and ServiceItemEntity.costMinor represent optional item-level pricing.
  • If the provider returns only a total and no reliable line-item prices, leave item-level cost null.
