Orca Privacy Policy

Effective date: July 15, 2026

This Privacy Policy explains how Orca handles information when you use the Orca Android app. Orca helps users organize vehicle maintenance records, import service documents, and optionally run AI-powered extraction on those documents.

Core storage model Vehicle records and imported documents are stored on your device in app-private storage.
AI processing If you use extraction features, Orca sends the selected source documents and relevant request data to OpenAI using your user-provided API key.
API key handling Your OpenAI API key is provided by you inside the app and stored locally on your device in encrypted form.
Current app scope As of this version, Orca does not include third-party advertising SDKs or third-party analytics SDKs.

1. Information Orca Handles

Depending on how you use the app, Orca may handle the following categories of information:

  • Vehicle information you enter, such as vehicle name, make, model, year, color, mileage, and photos.
  • Maintenance documents you import, including images, scans, and PDF files such as invoices, receipts, and service records.
  • Information extracted from imported documents, such as service dates, mileage, vendors, costs, and service items.
  • Your OpenAI API key, if you choose to save one inside Orca.
  • Basic technical request data needed to communicate with OpenAI when extraction is used.

2. How Orca Uses Information

  • To let you create and manage vehicle maintenance records.
  • To import, display, organize, and delete your maintenance documents.
  • To perform optional AI-powered document extraction when you choose to use that feature.
  • To build searchable maintenance records and summaries from imported documents.
  • To securely store and unlock your user-provided OpenAI API key when needed for extraction.

3. When Information Is Shared with Third Parties

Orca does not sell your personal information. Orca shares information with third parties only as needed to provide the features you choose to use.

OpenAI processing If you use Orca's extraction features, Orca sends the selected documents or images, along with related request content, to OpenAI so OpenAI can process the material and return extraction results. This happens only when you use the cloud extraction flow.

Orca uses your user-provided OpenAI API key to authenticate these requests. Orca does not currently include third-party advertising SDKs or third-party analytics SDKs.

4. Local Storage and Security

  • Vehicle records and imported source files are stored in app-private storage on your device.
  • Your OpenAI API key is stored locally in encrypted form.
  • Orca uses Android Keystore-backed encryption and device authentication flows when saving or unlocking the stored API key.
  • Orca excludes the stored OpenAI API key preference file from Android cloud backup and device-transfer backup rules.

No method of storage or transmission is completely secure. However, Orca is designed to reduce unnecessary exposure by keeping local records in app-private storage and requiring device authentication for protected API-key access.

5. Permissions and Device Access

Orca may access device capabilities needed for its core features, including:

  • Camera and document scanning flows: to scan paper maintenance documents.
  • Document and media selection: to let you choose images or PDF files to import.
  • Internet access: to send requests to OpenAI when you use cloud extraction features.
  • Biometric or device credentials: to protect stored API-key operations on supported devices.

6. Retention and Deletion

Orca keeps your vehicle and document data on your device until you delete it. You can delete vehicles and documents from within the app, which removes the related stored records and app-managed source files associated with those entries.

You can also clear the stored OpenAI API key from within the app's settings. If you uninstall Orca, app-private local data stored by the app is normally removed by Android.

7. Children's Privacy

Orca is not designed specifically for children. If you believe a child has provided information through Orca in a way that requires action under applicable law, contact the app publisher using the contact method listed below.

8. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. If the policy changes, the updated version should be posted at the current policy URL with a revised effective date.
